# D02B8 parallel preparation: metadata only

2026-10-17, Asia/Saigon. All new metadata choices are **PROPOSED engineering contracts**, not author details or execution approval. `src/mfvlr_research/d02b8/contracts.py` imports no model framework and contains no loader, checkpoint deserializer, optimizer or dispatch method. Validation can never authorize execution.

Training and inference configurations use a strict field set, A0, FP32 CPU and batch 1/2, with `execution_enabled: false` and `optimizer: null`. Frozen objective order and unit weights are retained. A dataset-manifest SHA-256 is mandatory; no placeholder may be interpreted as actual provenance. The inference metadata describes ownership/provenance, not a request to compute language losses: the accepted visual-only route remains the deployment route and does not require token IDs. Mode metadata does not instantiate either graph. Future GPU, B8, optimizer/scheduler settings and actual run authorization need separate contracts and approval.

Dataset entries require stable sample/subject identifiers, explicit train/validation/test membership, image source hash, supplied binary-mask hash and semantics, prompt metadata hash and preprocessing-contract hash. A real sample is class 0 with all-background mask semantics; EFS is class 1 with all-foreground semantics; local manipulation is class 1 with supplied binary localization. The validator checks metadata only, not actual pixel/mask values. It rejects duplicate sample IDs and shared subject groups across splits. It cannot establish absence of unrecorded identity leakage. Image `[3,224,224]` FP32 and mask `[224,224]` int64 are interface requirements, not permission to implement preprocessing. P2D15 dataset-mask preprocessing remains unapproved. No images, labels or mask files are loaded or generated here.

Checkpoint metadata requires full A0 ownership (508 tensors / 154,156,232 elements), seed 0, zero updates, no optimizer state, and hashes for actual state, source/config/tokenizer/dataset/loss contracts and backend. Numerical status must remain FAIL or NOT RUN; metadata cannot promote the failed baseline. These fields describe a future artifact; no model checkpoint has been produced, loaded or claimed validated. Deserialization trust, RNG-state resume and optimizer-state schema require later approval. Counts alone do not prove architectural fidelity or correct weight tying.

Mock/static tests use strings, dictionaries and tiny independent arrays only. Invalid modes, hidden execution switches, changed weights, missing hashes, label/mask conflicts, leakage, checkpoint updates and numerical acceptance claims are rejected. The separate read-only forensics tool has no production gradient-stream imports: its computation consumes only original binary shards.
